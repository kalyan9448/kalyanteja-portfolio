## 🌟 Highlights & Features

- **Performance-First Architecture**: Built with pure Vanilla HTML5, modern CSS3, and ES6+ JavaScript. Zero framework overhead, zero build steps, and instantaneous load times.
- **Dark Editorial Aesthetic**: Curated color palette (`#0a0a0a` background with `#d4b892` champagne accents) paired with Syne and Space Grotesk typography.
- **Fluid Micro-Interactions**:
  - Smooth animated lerp custom cursor with `mix-blend-mode: difference`.
  - Floating project image preview tracking cursor position.
  - IntersectionObserver-powered scroll reveal animations.
  - Dynamic animated stat counters and skill progress bars.
  - Parallax depth on hero typography.
- **Responsive & Accessible**: Seamlessly adapts across widescreen desktops, tablets, and mobile smartphones with a custom slide-out navigation drawer.

## 🚀 Local Development

To run this project locally without any dependencies or package managers:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kalyan9448/kalyanteja-portfolio.git
   cd kalyanteja-portfolio
   ```

2. **Open directly**:
   - Double-click `index.html` to open it in any modern browser.
   - Or serve with any static server:
     ```bash
     # Using Python:
     python -m http.server 3000

     # Using Node.js (npx):
     npx serve .
     ```

## 🌐 Deploy to GitHub Pages (One-Click Setup)

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/kalyan9448/kalyanteja-portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. On GitHub:
   - Go to your repository **Settings** > **Pages** (under "Code and automation").
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
3. Within 1–2 minutes, your portfolio will be live at:
   ```
   https://kalyan9448.github.io/kalyanteja-portfolio/
   ```
